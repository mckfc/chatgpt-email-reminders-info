A private reminder.

ChatGPT Email Reminders helps its owner review selected Gmail messages and remember clear appointments, deadlines, and expected deliveries in a dedicated Google Calendar.

How it works

  1. The owner authorizes read-only access to Gmail and access to calendars created by this application.
  2. A local utility filters selected Inbox categories, applies exclusions, and presents eligible email content for review in the owner's ChatGPT/Codex account.
  3. Clear events are added to an existing private reminder calendar under the owner's approval. Uncertain dates, changes, and cancellations are held for review.

Why Google access is needed

Gmail read-only access is used to identify messages and read relevant event details. The utility does not send email, mark messages read, or change Gmail labels.

Application-created Calendar access is used to maintain the dedicated reminder calendar. The utility does not invite attendees or edit the owner's primary calendar.

Built for personal use

This is a private, owner-operated utility, not a public sign-up service. This website provides information only: it does not connect to Google accounts or host email, calendar entries, credentials, or the local processing system.
